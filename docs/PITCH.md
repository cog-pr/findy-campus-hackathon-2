## 0:00–0:20　フック

自分のアラームって、自分に甘くない？  
**WakeMate** — 大事な朝を、信頼できる人が起こす共有アラーム。すぐ課題へ。

## 0:20–1:30　① 課題と解決

- **Who**: Wakee（絶対起きたい人）と Setter（親・恋人・同居人）
- **Gap**: 自分アラーム＝スヌーズ／LINE催促＝端末が鳴らない・起きたか不明
- **Unique**: ①他人がセット ②「起きた！」で閉じる ③サーバー側で時刻を守る

## 1:30–3:00　② 完成度（デモ物語）

物語: Setter → Wakee・大事な朝。

1. グループ作成 → 招待コード共有  
2. 参加 → 「3分後」で相手向けアラーム  
3. 発火: 対象にフルスクリーン警報 / 作成者に「起床待ち」バナー  
4. 「起きた！」→ 起床済み。無視すると未確認バナー  

**必ず言う**: Cloudflare Workers の公開 URL（未公開なら正直に「デプロイ中」）。  
前提: **両方タブを開いておく**（Push なし）。

## 3:00–4:20　③ 技術

1. アラーム作成で Agent の `schedule(発火時刻)`  
2. 発火で `status = fired` → `setState` で接続中クライアントへ配信  
3. confirm / timed_out も同じ仕組み  

Workers で API+UI を1デプロイ。難所は「端末の setTimeout に賭けない」こと。

## 4:20–5:00　④ チーム・締め

役割を一言ずつ。認証・通話・AI・Push・D1 は切って Must 一本。  
「大事な朝は、信頼できる人が起こす。」質問どうぞ。
