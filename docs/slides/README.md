## スライド 04（技術）メモ

図は実装どおり（Agents / DO Alarm / 開いているタブへのリアルタイム。D1・Web Push なし）。デモ前提として両方タブを開いておく旨も図にある。**14:12 差し替え済み**（旧 D1/Push 図ではない）。

口頭の流れ（任意）:

1. アラーム作成で Agent の `schedule(発火時刻)`
2. 発火で `status = fired` → `setState` で接続中クライアントへ
3. 「起きた！」/ timed_out も同じ仕組み
4. デモ前提: **両方タブを開いておく**（Push は Won't）
