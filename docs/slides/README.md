## TECH CORRECTION（スライド 04）

PNG の図は **D1（状態）+ Web Push（端末通知）** になっているが、**実装・仕様書と不一致**。

| 図の表記 | 実際（言うこと） |
|----------|------------------|
| D1 で状態管理 | **Agents の `setState`（Durable Objects 内）** |
| Web Push で通知 | **接続中タブへリアルタイム配信 + フルスクリーン警報**（Push なし） |
| Durable Objects Alarm | **Agents の `schedule(発火時刻)`**（ここは方向性OK） |

口頭の正:

1. アラーム作成で Agent の `schedule(発火時刻)`
2. 発火で `status = fired` → `setState` で接続中クライアントへ
3. 「起きた！」/ timed_out も同じ仕組み
4. デモ前提: **両方タブを開いておく**（Push は Won't）

**言わない**: 「D1に保存」「Web Pushで起こす」  
デモ前に図を差し替えるか、04 を見せつつ「実装は Agents の schedule + setState。Push/D1 は切った」と訂正する。
