## 各10点チェック

### ① 課題と解決策
- [ ] Who（起きる人／起こす人）が言える
- [ ] 既存の穴が言える
- [ ] 独自性が「他人セット＋起きたまで閉じる」で一言

### ② プロダクト完成度
- [ ] Must 導線が追える
- [ ] Workers 公開 URL を口＋スライドで示す（`https://findy-campus-hackathon-2.trco0430.workers.dev`）
- [ ] 触れる／触れる予定が曖昧でない
- [ ] （口頭）起きた／未確認まで見える、を一言

### ③ 技術チャレンジ
- [ ] 「なぜその部品か」が言える（DO Alarm）
- [ ] やらなかった選択（端末タイマー）と比較がある
- [ ] スタック全部列挙に逃げていない

### ④ プレゼン・熱量
- [ ] 1本の朝の物語
- [ ] 役割が具体（実名差し替え済み）
- [ ] スコープを切った覚悟
