## 4. 原則・出典

| 原則 | このチームのルール |
|------|-------------------|
| 1メッセージ | 審査員が「この枚で覚えろ」は **1文だけ**。2つ目は次の枚へ |
| 明らか | スライドだけ見て見知らぬ人が同じ1文を言える（stranger test） |
| 読める | 会場後ろから読める字。詳細は口頭。段落禁止 |
| タイトル＝結論 | 「課題」「技術」ラベルではなく、**言い切り**を大きく |
| 図は迷路にしない | 複雑図より **3ステップ以内**／その1文の意味を助けるときだけ |
| ハッカソン向けに切る | 市場・収益・調達は入れない（採点外） |
| 採点に直結 | 各枚は審査4軸のどれかを埋める。埋めない枚は削除 |
| 枚数は後 | メッセージ一覧→一文→マージ／スプリットで枚数 |

### 出典

- [YC — How to design a better pitch deck](https://www.ycombinator.com/library/4T-how-to-design-a-better-pitch-deck)（legible / simple / obvious）
- [Pitch Deck Essentials（短尺・1 key message）](https://israelcampusbeat.org/pitch-deck-essentials-how-to-sell-your-idea-in-3-minutes/)
- 日本語ピッチでも同型: 1スライド1メッセージ・タイトルは結論・文字最小

### 投影の文字サイズ（Phase B 固定値）

| 要素 | 最小目安（16:9 投影） |
|------|----------------------|
| 結論1文（主役） | **clamp 相当で 48px 以上**（理想 56–72px） |
| 補助ラベル（製品名など） | 20–28px |
| 本文・注釈 | 原則置かない。置くなら 28px 以上かつ短い |
| 1枚の文字量 | 日本語 **おおむね 40字以内の結論1文**＋その文を助ける視覚のみ |

## 5. Phase B デザイン制約

1. 各スライドの視覚的主役は **結論1文のみ**（巨大・ステージを埋める）
2. イラスト／パネルは「その1文の意味を助ける」場合だけ（装飾ノイズ禁止）
3. 色変更や余白いじりだけで「デザインした」ことにしない。**スカスカ余白＋小さい字は不合格**
4. 出して終わり禁止: 全枚スクショ自己精査後に渡す（`presentation/qa/`）
5. URL・人名はプレースホルダのまま渡さない（差し替えチェック必須）
